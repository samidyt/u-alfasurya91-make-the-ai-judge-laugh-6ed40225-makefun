`/output/entry.txt` (program/v1 harness, Node 22, standard library only).

## The line (97 chars)

I asked IT for a second monitor and got a lecture on minimalism — from a man with three monitors.

## Why this line

- True to the office: everyone has met the IT gatekeeper and the second-monitor request.
- Surprising turn: the lecture on minimalism lands, then the last words flip it — the lecturer has three monitors.
- Tight: one breath, every word earning its place, no setup wasted.
- Fresh: the hypocrisy is observed, not a stock "meeting could have been an email" line.
